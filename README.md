\# 🛡️ AEGIS-X



\### AI-Based Intelligent Video Analytics Platform for Border Surveillance



\*\*An AI-powered intelligent surveillance platform designed to enhance border security using existing CCTV infrastructure.\*\*



\---



\## 📌 Project Overview



AEGIS-X is an AI-based intelligent video analytics platform designed to assist security personnel in monitoring border areas through existing CCTV infrastructure.



The system processes video feeds and sensor inputs to identify suspicious activities, detect objects, monitor movement and generate alerts for security personnel.



Instead of replacing existing surveillance infrastructure with expensive smart cameras, AEGIS-X aims to integrate intelligent analytics into conventional CCTV systems.



\## 🎯 Problem Statement



Traditional border surveillance systems require continuous human monitoring of CCTV feeds. This creates several challenges:



\* Continuous manual monitoring is difficult.

\* Suspicious activities may go unnoticed.

\* Identifying unusual movement takes time.

\* Multiple surveillance feeds are difficult to manage.

\* Security personnel need faster alerts and actionable information.



AEGIS-X aims to address these challenges through AI-powered video analytics and centralized monitoring.

\## 🏗️ System Architecture



The proposed system follows a modular architecture:



1\. \*\*Input Layer:\*\* Receives video and sensor inputs.

2\. \*\*Processing Layer:\*\* Processes incoming data.

3\. \*\*Detection Layer:\*\* Identifies objects and suspicious activities.

4\. \*\*Data Fusion Engine:\*\* Combines relevant detection information.

5\. \*\*Explanation Layer:\*\* Provides interpretable information.

6\. \*\*Alert and Logging Layer:\*\* Records events and generates alerts.

7\. \*\*Dashboard Layer:\*\* Displays monitoring information.

\## ⚙️ Installation and Setup



\### Prerequisites



\* Python 3.10 or above

\* Git

\* VS Code (recommended)



\### Step 1: Clone Repository



```bash

git clone https://github.com/sarvesh-2307/Aegis-x.git

```



\### Step 2: Navigate to Project



```bash

cd Aegis-x

```



\### Step 3: Create Virtual Environment



```bash

python -m venv venv

```



\### Step 4: Activate Virtual Environment



For Windows:



```bash

venv\\Scripts\\activate

```



\### Step 5: Install Dependencies



```bash

pip install -r requirements.txt

```



\### Step 6: Run Application



```bash

python app.py

```



Open your browser and visit:



```text

http://127.0.0.1:5000

```



\*The application URL and startup instructions should be verified against the actual Flask configuration.\*
